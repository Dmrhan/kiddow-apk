# Kiddow — Android Uygulaması

Veliler için Kiddow anaokulu uygulamasının Android kurulum dosyası.

**İndirme bağlantısı:** https://github.com/Dmrhan/kiddow-apk/raw/main/kiddow.apk

Telefonunuzda bağlantıya dokunun, inen `kiddow.apk` dosyasını açın ve kuruluma izin verin.
Güncel sürüm: 1.0.1 (build 6) — 5 Kasım 2026. Fotoğraf yükleme düzeltmesi için yeni APK sürümünü mevcut uygulamanın üzerine kurun; uygulamayı silmeyin. Sonraki uygulama içi güncellemeler otomatik gelir.
